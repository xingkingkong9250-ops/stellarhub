## 2. UI 设计元素归纳

### 2.1 配色体系

#### 共性

- **深色模式为主**，但不使用纯黑，统一采用「中性炭灰」底色（≈RGB 13–23）
- **品牌主色用作选中/激活态强调**，不用作大面积铺色
- **状态色克制**：仅在警示徽标、进度数字、缺失态等小面积处出现
- **半透明遮罩**统一用于缩略图覆盖态（缺失/选中/加载中）

#### 千岚·天工的差异化

- **渐变品牌色**：深蓝→紫的渐变带 + 青色高光强调
- **玻璃态卡片**：卡片背景带模糊与流光，营造「应用商店」的产品质感
- **节日徽标**：版本号后跟「七夕特辑」等情绪化标签

#### 千岚·商城的差异化

- **冷峻中性**：几乎是纯灰阶 + 单一蓝色选中色
- **缩略图原色保留**：网格中资产缩略图保持原色彩，UI 不抢戏
- **选中态边框**：选中卡片用 2px 蓝色外描边而非整体改色

### 2.2 窗口构成

| 元素 | 千岚·天工 | 千岚·商城 | QL World 当前 |
|---|---|---|---|
| 标题栏 | 含 Logo + 名称 + 标准三键 | 标准三键 | 标准三键 + Title 绑定 |
| 左侧栏 | 导航分类（带计数）+ 用户身份/NAS 状态 | 筛选维度分组 | B1 素材库树 + 收藏夹 + Top50 标签 + 贴图组 |
| 中部 | 3×2 卡片网格 | 资产缩略图网格 + 顶部工具条 | B2 画廊网格/列表 |
| 右侧栏 | — | 资产详情 + 相关资产 | B3 文件详情 + 标签 + 备注 |
| 底部 | 版本号 + 节日徽标 | 进度 + 快捷键 + 版本号 | C1 状态/进度/AI 档位 |
| 搜索 | 顶部搜索框 | 顶部搜索框 + 模式切换 | A1-4 搜索框 + A1-5 模式下拉 |

### 2.3 按钮 / 控件

#### 千岚·天工

- **卡片操作组**：「打开目录 / 打开应用 / ⋯」三件套，主操作（打开应用）用蓝色高亮按钮，次操作用文字按钮
- **版本下拉**：每张卡片内嵌版本选择器
- **收藏心形**：Banner 右上角浮层
- **兼容性徽标**：Win11 / UE 等技术标识以小图标呈现

#### 千岚·商城

- **筛选维度**：每个维度用单选 Chips（如「全部 / 官方 / 第三方」）
- **顶栏工具条**：浏览方式 / 资产包 / 截图 / 排序 / 最近入库 一组平铺下拉
- **路径操作组**：「完整路径 / 复制路径 / 在资源管理器中打开」三按钮
- **缩略图选中态**：2px 蓝色外描边，不改卡片背景

### 2.4 信息架构

#### 千岚·天工（应用分发视角）

- 一级：分类（全部 / 自研 / 第三方 / 收藏夹 / 已安装 / 可更新 / 开发者）
- 二级：每张卡片的应用身份 + 版本 + 操作
- 计数显式：每个分类后括号数（95 / 41 / 54 / 0 / 19 / 0）

#### 千岚·商城（资产浏览视角）

- 一级（筛选维度分组）：来源格式 / UE 版本 / 通用 3D / 资产类型 / 建筑风格
- 二级（顶栏工具条）：浏览方式 / 资产包 / 截图 / 排序 / 最近入库
- 三级（详情栏）：元数据 / 标签 / 分类链 / 路径 / 相关资产

## 4. 演进目标分项

> 落地优先级：P0 = 高识别度低成本，建议下个里程碑；P1 = 中等成本；P2 = 长期可选项

### 4.A 配色

#### 4.A.1 选中态边框色（P0）

**目标**：画廊网格选中图卡使用 2px 主题 Accent 外描边，不改卡片底色。

**理由**：千岚·商城实测方案；低成本、识别度高、与现有 [Dark.xaml Accent #7C5CFF](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Themes/Dark.xaml#L27) 直接复用。

**落地提示**：在 `GridCardTemplate` 的外层 Border 上绑定 `IsSelected` → `BorderBrush` + `BorderThickness` 转换器；列表态用左竖条高亮（避免整行底色与文本对比下降）。

#### 4.A.2 品牌渐变位（P1）

**目标**：仅用于标题栏 Logo 区 / 加载进度条 / AI 分析按钮 hover 态，不扩大到正文背景。

**理由**：参考千岚·天工的渐变带用法；当前 QL World 顶栏偏平，渐变可提升品牌识别度但不破坏中性炭灰底。

**落地提示**：新建 `LinearGradientBrush` 资源 `AccentGradientBrush`（#7C5CFF → #A48BFF），主题文件中按 Dark/Light 各自定义；不替换 `AccentBrush`。

#### 4.A.3 缩略图遮罩统一走 OverlayBrush（P0，已落地）

**目标**：所有覆盖在缩略图上的半透明遮罩一律用 [OverlayBrush](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Themes/Dark.xaml#L39)，禁止硬编码 hex。

**状态**：已在 M2 落地并写入 project_memory。本文档列为基线条款，后续新增遮罩态沿用此规则。

### 4.B 窗口与布局

#### 4.B.1 顶栏工具条扩展（P1）

**目标**：参考千岚·商城顶栏「浏览方式 / 资产包 / 截图 / 排序 / 最近入库」，QL World 在 A1 区现有「视图切换 / 搜索 / 排序」基础上增加「最近入库」时间筛选下拉。

**理由**：千岚·商城的「最近入库」是高频入口；QL World 当前需手动滚动查找新导入图片。

**落地提示**：A1 区加 `「最近入库 ▾」` 下拉（今天 / 7 天 / 30 天 / 全部），与 [ShellWindow.xaml](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Views/ShellWindow.xaml) 现有 A1-3 视图切换并列；下拉选中态映射到 LibraryFilter。新增编号 A1-9。

#### 4.B.2 左栏筛选维度分组化（P2）

**目标**：参考千岚·商城左栏「来源格式 / UE 版本 / 资产类型 / 建筑风格」分组化筛选，QL World 在 B1 现有「素材库树 / 收藏夹 / Top50 标签 / 贴图组」基础上增加「按属性筛选」折叠组（颜色 / 分辨率 / 文件大小 / 评分）。

**理由**：千岚·商城的分组筛选是用户浏览资产库的核心心智模型；QL World 现有筛选偏「分类树」单一维度。

**落地提示**：B1 底部追加 `B1-5 属性筛选` 折叠组，每组单选 Chips；折叠态默认收起避免挤占主区。需要先评估与 [Top50 标签 B1-3](file:///c:/AI_Programming/APP/QL_World_dotnet/docs/UI_NUMBERING.md) 的边界。

#### 4.B.3 详情栏「相关资产」section（P1）

**目标**：参考千岚·商城右栏底部「相关资产」缩略图行，QL World 在 B3 现有 [B3-8 找相似按钮](file:///c:/AI_Programming/APP/QL_World_dotnet/docs/UI_NUMBERING.md) 基础上，将「找相似」从按钮扩展为内嵌 4–6 张缩略图行（横向滚动）。

**理由**：当前 B3-8 是模态触发，用户需点击后切回画廊看结果；内嵌预览减少切换。

**落地提示**：B3 底部新增 `B3-9 相关资产` 横向缩略图条；数据复用 [SemanticSearchService](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Services) 缓存；无 embedding 时整段隐藏不报错。

### 4.C 控件

#### 4.C.1 卡片操作组三件套（P2）

**目标**：参考千岚·天工卡片「打开目录 / 打开应用 / ⋯」三件套模式，QL World 网格卡片在 hover 态浮出「定位 / 复制路径 / 在资源管理器中打开」三按钮。

**理由**：当前 QL World 这些操作在 B3-2 详情栏；高频操作前置到卡片可减少右栏切换。

**落地提示**：在 [GridCardTemplate](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Views/ShellWindow.xaml#L31) 外层 Border 上加 hover 触发的浮层 Border（默认 Collapsed），按钮命令复用 B3-2 现有命令；注意虚拟化面板下浮层不要破坏 Measure 性能。

#### 4.C.2 类别 / 状态徽标统一化（P1）

**目标**：参考千岚·天工「Win11 / UE」徽标 + 千岚·商城「UE 版本」徽标，QL World 在卡片缩略图右下角增加「来源」徽标（本地 / 云端 / AI 分析）+ 「UE 版本」徽标（如适用）。

**理由**：当前 QL World 卡片仅显示文件名 + 尺寸 + 评分，信息密度低于参考样本；但 QL World 是图片库不是 3D 资产库，UE 版本徽标仅在有 UE 集成时启用。

**落地提示**：徽标复用 [OverlayBrush](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Themes/Dark.xaml#L39) 半透明底 + 反色文字；编号 B2-3-OL1（overlay 标记位）。

### 4.D 信息密度

#### 4.D.1 卡片元数据条（P1）

**目标**：参考千岚·商城卡片「文件名 + 尺寸 + UE 版本」三行布局，QL World 网格卡片在现有「文件名 / 尺寸·评分」基础上增加第三行「标签摘要（取前 2 个 + 「+N」）」。

**理由**：千岚·商城卡片三行密度均衡，QL World 当前两行偏稀疏；标签是 QL World 的核心分类维度，前置可见降低筛选成本。

**落地提示**：在 [GridCardTemplate StackPanel](file:///c:/AI_Programming/APP/QL_World_dotnet/src/QL.World/Views/ShellWindow.xaml#L49) 后追加 `TextBlock TagsSummary`；超过 2 个标签用 `+N` 折叠。

#### 4.D.2 顶栏计数显式化（P0）

**目标**：参考千岚·天工侧栏「全部 95 / 自研 41」+ 千岚·商城顶栏「2446 资产包」，QL World 在 B1 各分类节点后显式计数。

**理由**：当前 QL World 仅在 B2-1 计数条显示总数，左栏节点不显示子数；用户筛选前无法预估结果规模。

**落地提示**：[TagTree](file:///c:/AI_Programming/APP/QL_World_dotnet/docs/UI_NUMBERING.md) 节点渲染时绑定 `Count` 属性，格式 `名称 N`；性能考量：Count 走 ViewModel 缓存不实时查 SQLite。

**状态**：经 U1-B 核实已落地（M1–M4 各阶段逐步实现）。B1 四类树节点（TagTree.CategoryNodes / CollectionTree.CollectionNodes / TagTree.TopTagNodes / PbrGroupTree.GroupNodes）的 Count/MemberCount 绑定均已落到 XAML（ShellWindow.xaml L274-382），ViewModel 通过 SQLite GROUP BY 查询填充。本节列为基线条款，后续新增树节点沿用此模式。

### 4.E 交互细节

#### 4.E.1 底部快捷键提示（P0）

**目标**：参考千岚·商城底部「快捷键提示」，QL World 在 [C1 状态栏](file:///c:/AI_Programming/APP/QL_World_dotnet/docs/UI_NUMBERING.md) 右侧增加快捷键提示区（如 `Ctrl+1…5 评分 · F2 重命名 · Del 移除`）。

**理由**：低成本可发现性提升；当前 QL World 快捷键仅文档化，UI 不提示。

**落地提示**：C1 拆为 `C1-L 状态文本 / C1-C 进度 / C1-R 快捷键提示`；提示按当前焦点上下文切换（如选中图片时显示评分快捷键）。

#### 4.E.2 品牌化版本号（P1）

**目标**：参考千岚·天工右下角「v2.10.0 七夕特辑」、千岚·商城「v1.2.0」，QL World 在 C1 右侧版本号后增加可选的「里程碑标签」（如 `v1.0.0 · M4 发布基线`）。

**理由**：版本号品牌化有助于里程碑可识别；节日徽标不采纳（详见 §5）。

**落地提示**：版本号绑定 ViewModel `VersionLabel` 属性；里程碑标签从 csproj `<Version>`+`<Description>` 解析；不强制。

#### 4.E.3 节点折叠态计数（P2）

**目标**：参考千岚·天工侧栏分类括号计数，QL World 在 B1 收藏夹树与贴图组树的折叠态节点也显示子项总数。

**理由**：当前 QL World 仅展开态可见计数；折叠后丢失全局感。

**落地提示**：TreeView 节点 `Header` 模板统一带 `Name (Count)` 渲染；Count 包含所有子孙节点。

## 5. 不采纳项与边界

| 项 | 不采纳理由 |
|---|---|
| 节日徽标（七夕特辑类） | QL World 是工具型应用，非分发型产品；情绪化标签偏离定位 |
| 应用商店式卡片网格（3×2 大卡） | QL World 卡片是单图缩略图，不是应用身份卡；尺寸不匹配 |
| 玻璃态卡片背景 | 与 QL World 中性炭灰基线冲突；缩略图原色已足够丰富，玻璃态会喧宾夺主 |
| 多色彩渐变背景 | 大面积渐变会干扰缩略图识别；仅 Logo/进度条/AI hover 使用（见 §4.A.2） |
| NAS 连接状态显式标识 | QL World 当前是单机应用；如未来引入 NAS 同步再评估 |
| 大型 Banner 装饰图 | 工具型应用不需要营销位 |
| 第三方应用分发 | QL World 是个人图库工具，不分发第三方应用 |
