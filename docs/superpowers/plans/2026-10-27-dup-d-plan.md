## 3. 关键语义

- 组状态：组内成员行状态一致。`保留全部` → 整组 `dismissed`。
- `删除选中`：调用 `ImageQueryService.Remove`（不删磁盘，8 秒内可撤销 `Restore`）；
  删除后组内剩余成员 == 1 → 整组 `resolved`；剩余 0 → 组自然消失。
- 推荐保留：组内按 `宽×高` 降序、再按 `file_size` 降序取第一张打标。
- 类型筛选：组内全部 `kind='exact'` → 严格同图；否则近似变体。
- 扫描：`DuplicateScanService.ScanAsync` 后台执行 + `IProgress` 进度 + 取消；取消不写表。
- 无 AI 时入口不置灰（L1 恒可用）。
