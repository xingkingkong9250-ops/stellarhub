- 日期：2026-10-27
- 设计真源：`docs/superpowers/specs/2026-10-27-duplicate-detection-design.md` §4.1/§4.4
- 版本：0.16.0（DUP-A~E 共用，本阶段不升位）

## 1. 目标

为扫描的「模糊边界带」加一道可选终审：L1 阈值与 L2 阈值之间的候选对
（pHash 汉明距离 11~18，或同 model_id 余弦 0.88~0.92）在云端 VLM 可用时
双图送审，确认才入组并把 `level` 落 `'L3'`，否决则丢弃；不可用静默跳过，
L1/L2 结果照常输出。

## 3. 关键语义

- 边界带：pHash 距离 `> SameImageMaxDistance(10)` 且 `<= 18`；余弦 `>= 0.88` 且 `< 0.92`。
- 送审输入：优先已缓存 256px Thumb WebP（远程图不必下载整图）；无缩略图的本地行用原图路径；远程行无缓存则跳过该对。
- 判定：`SameImage=true && Confidence>0` → 入组，`level='L3'`，`kind` 取触发层
  （pHash 边界 → `exact`，余弦边界 → `variant`）；`SameImage=false && Confidence>0` → 丢弃；
  `Confidence<=0`（未配置/网络/解析失败）→ 丢弃该对，不中断扫描。
- 层级优先级：L1 > L3 > L2（同一对既在确定集合又落入边界带时不重复送审）。
- 组内存在 `level='L3'` 行即「已终审」（W8 徽标 L3），不加新列。
- 取消：L3 阶段中途取消 → 结果 `Cancelled=true`，不写候选表。

## 4. 验收标准

1. Release 编译 0 警告 0 错误。
2. 全量单测通过（当前基线 819，新增 DUP-E 用例）。
3. 无云 AI 时扫描结果与 DUP-C 完全一致（边界带静默跳过）。
4. UI_NUMBERING / CHANGELOG 同步；AI 不可用不置灰入口行为不变。
