§0编号规则与使用方法

编号是锁定位置的唯一锚点：调整布局前先在图上找到目标编号，改完 XAML 后回来核对编号仍指向同一功能。点击图中任意编号芯片，右下角弹出完整说明，表格行同步高亮；表格行也可点击反查。悬停芯片时底部状态栏显示摘要。

W{数字}
顶级窗口，按创建顺序编号（W1 主窗口 … W9 素材组织）
W1/A·B·C
W1 下 A=顶部横区/页签、B=主分区、C=底部区
W1/B1-6-1
编号下钻到控件；后缀字母为具名变体（如 B2-3-BRW）
铁律
删除即作废不复用 · 新增顺延 · 每次 UI 变更必须同步 UI_NUMBERING.md
